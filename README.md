# The Vacuum's Alibi: One Line, 200 Characters

Entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on make.fun.

One funny excuse a robot vacuum gives for missing a spot, at most 200 characters. The house judge reads entries two at a time and keeps the one that lands hardest.

> The dust under the couch has unionised. I am in negotiations. I will not cross a picket line.

## How it works

`main.ts` (Node 22, no dependencies) writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates it first — 1–200 characters, not only whitespace, a single line — then reads it back and verifies it is byte-identical.

```sh
node main.ts
```
